# User Stories

## Completed in the baseline

- As a job seeker, I can add an application with required details so that I can track an opportunity.
- As a job seeker, I can view all saved applications after a refresh so that my data persists.
- As a job seeker, I can edit application details and status so that the tracker remains current.
- As a job seeker, I can delete an application I no longer need.
- As a job seeker, I can see calculated totals, recent applications, and status distribution on a dashboard.
- As a user on a smaller screen, I can use mobile navigation and scroll the table safely.

## Planned for Student 2

- As a user, I can search, filter, and sort applications.
- As a user, I can manage applications on a Kanban board.
- As a user, I receive enhanced edit/delete interaction feedback.
